#  Dashboard E-commerce avec IA

##  Objectif
Développer un tableau de bord interactif pour analyser les ventes e-commerce avec des indicateurs clés (KPI), des visualisations dynamiques et des fonctionnalités d’intelligence artificielle.

---

##  Fonctionnalités principales

###  Analyse des performances
- Chiffre d’affaires total
- Profit total
- Marge moyenne
- Analyse par produit, région, pays
- Filtres dynamiques (année, catégorie, région…)

 Visualisations interactives
- Évolution des ventes dans le temps
- Ventes par catégorie
- Top produits
- Carte géographique des ventes
- Analyse multidimensionnelle

---

##  Intelligence Artificielle

###  Prévision des ventes
- Modèle de régression simple
- Prédiction du chiffre d’affaires sur 3 mois

###  Segmentation clients
- Clustering K-means
- Identification des segments clients

###  Détection d’anomalies
- Identification des ventes anormales
- Analyse des anomalies dans les données

---

##  Technologies utilisées
- Python
- Streamlit
- Pandas
- Plotly
- Scikit-learn
